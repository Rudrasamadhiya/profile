    02 new — the agent toolkit

    Giving agents hands on real phones.

    Claude Code, Cursor and Antigravity can write your app, but they can't see it. So I built the bridges: three open-source packages on npm that let agents look at a real device, tap, type, scroll, debug, and even cut the launch video.

    Android Agent Bridge

    android-agent-bridge · Kotlin · TypeScript
    ↗

    Give your agent a whole Android phone. Screenshots with numbered elements, on-device OCR, taps, typing, device controls and AirDrop-style file transfer. One npx, one QR scan.
